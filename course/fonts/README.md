# Fonts

Google Fonts, latin subset, variable weight 400–700. `build.py` embeds them in the page as data URIs, so the course needs no network for its type.

| File | Family | License |
|---|---|---|
| `Lexend.woff2` | [Lexend](https://fonts.google.com/specimen/Lexend): headings | [OFL](OFL-lexend.txt) |
| `SourceSans3.woff2`, `SourceSans3-Italic.woff2` | [Source Sans 3](https://fonts.google.com/specimen/Source+Sans+3): body text and diagrams | [OFL](OFL-sourcesans3.txt) |
| `JetBrainsMono.woff2` | [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono): code | [OFL](OFL-jetbrainsmono.txt) |
